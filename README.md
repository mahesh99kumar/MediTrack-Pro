# MediTrack Pro

## About the Project

MediTrack Pro is a web-based medical store management system developed using Python and Flask. It helps manage medicine inventory, customer details, billing, invoices, sales history, and reports.

## Objectives

- To simplify medical store management.
- To maintain medicine inventory records.
- To manage customer information.
- To generate bills and invoices.
- To view sales history and reports.

## Features

- Dashboard
- Medicine inventory management
- Customer management
- Billing and invoice generation
- Sales history
- Reports

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Project-configured database

## Project Structure

- `app.py` — Main application
- `config.py` — Application configuration
- `database.py` — Database-related functions
- `requirements.txt` — Python dependencies
- `templates/` — HTML templates
- `static/` — Static assets such as CSS, JavaScript, and images

## Installation and Usage

1. Install Python 3.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Install the required packages:

   `pip install -r requirements.txt`

5. Configure the database as required by the project.

6. Run the application using the appropriate command for the configured database and environment.
